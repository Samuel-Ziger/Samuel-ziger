SAMUEL ZIGER — README CYBER

COMO USAR

1. Clone o repositório Samuel-Ziger/Samuel-ziger ou baixe e extraia o ZIP.
2. Coloque README.md, README.en.md e a pasta assets/ na raiz do seu repositório de perfil.
3. Faça o commit dos arquivos. Preserve exatamente os nomes e a capitalização dos caminhos.
4. Abra o README no GitHub. O seletor PT-BR / EN alterna entre as duas versões.

Para visualizar antes de enviar, abra preview/README-preview.html no seu navegador.

O README referencia as imagens por caminhos relativos. Envie também a pasta assets/ para que o banner, o terminal e os badges apareçam.

CERTIFICADOS

Atualizado em 14/11/2026, em conjunto com o repositório Samuel-Ziger/Certificado.
Os links dos certificados e dos currículos em português e inglês apontam para os arquivos desse repositório.
O inventário documenta 44 credenciais distintas: 5 certificações com exame (API-RTA, CRTA, SYCP e duas do IBSEC) e 39 certificados de conclusão de curso.
A API-RTA foi emitida pela CyberWarFare Labs em 14/11/2026. O perfil inclui o código da credencial, o PDF e o programa oficial da certificação.
Os cursos de Fundamentos de Assembly para Pentester e Desenvolvimento de Exploits e de Fundamentos de Análise e Desenvolvimento de Malwares foram incluídos em Fundamentos de segurança.
ISC2 Candidate aparece como participação no programa de candidatos; Learn-A-Thon aparece como programa de aprendizagem. Essas participações não entram na contagem de 44 credenciais.
Os 35 cursos que complementam os quatro destaques Cisco/Desec estão agrupados em seis blocos expansíveis.
As datas e os códigos das novas credenciais foram conferidos nos documentos. As demais datas e validades já presentes no perfil foram preservadas.
Os links "Validar" foram extraídos dos próprios documentos; não foram criados por dedução.
As duas prévias HTML acompanham o conteúdo atualizado dos READMEs.

PERSONALIZAÇÃO

- Edite os textos diretamente nos dois READMEs.
- Para trocar o banner, substitua assets/banner.png.
- Para alterar a animação, edite os textos de assets/terminal.svg.
- Os SVGs são editáveis e não usam scripts, recursos externos ou chaves de API.
- As estatísticas opcionais, dentro de uma seção recolhível, usam o serviço externo que já estava no README original.
- O tema claro ou escuro da página é definido pelo GitHub do visitante. A identidade visual escura permanece no banner e nos assets.
- A prévia local aproxima a apresentação do GitHub; não é uma captura de um perfil publicado.

A pasta preview/ e os arquivos de instrução são opcionais no repositório. Os dois READMEs e a pasta assets/ compõem o perfil.
